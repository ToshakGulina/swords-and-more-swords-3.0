# Проверка на сервере Bedrock — 6 ноября 2026

Запущен сервер из предоставленного архива, версия **1.26.62.1**. Каждая версия аддона проверена в отдельном тестовом мире с исходными, неизменёнными файлами пакетов. Сервер работал без игроков и в изолированной сети. Ванильные команды, создание свиньи и стойки для брони, помещение алмаза в слот и проверка слота успешно прошли контроль.

## Что показал сервер

| Архив аддона | Результат |
|---|---|
| **2.8.14** | Все 42 предмета отвергнуты при загрузке: сервер требует формат предметов 1.20.0 или новее. В мире с экспериментами каждый из 42 ID дополнительно проверен командой `/give`: сервер не распознал ни один. В обычном мире такие же 42 ошибки загрузки; Bee Sword отдельно также отвергнут командой. |
| **2.8.8** | В мире с экспериментами те же 42 ошибки формата; каждый из 42 ID дополнительно отвергнут командой `/give`. |
| **1.6** | В мире с экспериментами все 26 предметов последовательно помещены на стойку командой `/replaceitem`; после каждого размещения отдельная проверка `hasitem` находила именно этот предмет. Контрольный алмаз также найден. Это подтверждает регистрацию и наличие предметов, но не работу их способностей. |

В обоих тестах `/give` без игроков сервер для известного ванильного алмаза отвечал «No targets matched selector», а для заведомо несуществующего предмета — ошибкой разбора ID. Это позволяет отличать зарегистрированный предмет от неизвестного, несмотря на отсутствие игрока.

### Дополнительные наблюдения для 2.8.x

- Сервер сообщил об ошибках 14 рецептов из-за отсутствующих или некорректных предметов/блоков, в том числе рецептов Bedrock Sword, Cactus Sword и Nether Star Sword.
- JavaScript аддона не запустился: сервер сообщил, что модуль `@minecraft/server` не распознан. Он также отклонил множество компонентов событий `run_command`.
- Сущности `entity:alpha_wolf`, `entity:bee_sword` и `entity:ghost` удалось создать и найти селектором. Однако это **не доказывает**, что их способности, выпадение мечей или все события работают: в журнале есть ошибки событий.
- В 2.8.14 вручную запущенное событие `minecraft:wolf_sword` получило ответ об успешном выполнении; структуры `wolf_sword` и `glass_sword` сервер тоже сообщил как загруженные. Эти сообщения сами по себе не подтверждают получение предмета или работу способности.

### Настройки и границы

Для сравнительных тестов в копиях миров были записаны флаги `upcoming_creator_features`, `gametest`, `data_driven_items`, `experimental_molang_features`; сервер сообщил об активных экспериментах `ucft, gtst, ddi_, mola`. Для 2.8.14 дополнительно проверен мир без экспериментов — результат по формату предметов и запуску скрипта не изменился. Это не проверка всех возможных комбинаций и не инструкция по настройке конкретной версии клиента.

Игрок и клиент не подключались: урон, прочность при использовании, крафт, вероятности выпадения, визуальные эффекты и поведение мечей в бою не проверены. Поэтому версия 1.6 выглядит совместимее по регистрации предметов, но её полная работоспособность не подтверждена. Вывод касается именно проверенной версии сервера; другие версии Minecraft не испытывались.

Сжатые журналы с командами и ответами, без идентификаторов сессии, и проверенные списки предметов: `data/server-runtime-2026-11-06/`. Исходные архивы не изменялись.
