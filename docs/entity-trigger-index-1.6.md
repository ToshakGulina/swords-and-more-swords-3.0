# Таймеры, сенсоры и возраст сущностей — 1.6

Из 28 разобранных entity-файлов извлечено **2** компонентов с 6 выбранными точными ключами только из базового `components` и `component_groups`. Полные значения сохраняют вложенные события, target, фильтры и порядок списков. В 2.x базовый sensor player содержит множество отдельных элементов; [отдельная таблица player](player-sensor-index.md) показывает их по одному.

Это буквальные объявления, а не доказанные активные таймеры или последовательность срабатываний. Группы могут быть неактивны, вытесняться другими или включаться по разным событиям; repeat/random, пропущенные поля, target и область исполнения не следует дополнять значениями по умолчанию. Числа `time`, `duration` и другие величины сохранены в единицах исходных полей; одинаковый формат значений в разных компонентах не доказывает одинаковую семантику. Неточности JSON и внешние/ванильные определения остаются вне структурного разбора.

Количество выбранных компонентов: `minecraft:timer` — 1, `minecraft:environment_sensor` — 1, `minecraft:block_sensor` — 0, `minecraft:ageable` — 0, `minecraft:on_target_acquired` — 0, `minecraft:on_wake_with_owner` — 0.
У `1` записей timer: пустых объектов 0; отсутствуют поля `time` — 0, `looping` — 0, `randomInterval` — 1, `time_down_event` — 0. Отсутствие поля отдельно от явного false, null, нуля или пустого списка.

- Неразобранные JSON: `Sword_B/entities/blaze2.json` (<string>:78 Unexpected "}" at column 1); `Sword_B/entities/bone2.json` (<string>:75 Unexpected "}" at column 1); `Sword_B/entities/shulker2.json` (<string>:75 Unexpected "}" at column 1). Их компоненты здесь не учтены.
- Повторные ключи: нет. JSON5 оставляет последнее значение.
