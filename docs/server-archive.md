# Серверный архив: безопасная проверка без запуска

Источник — файл `bedrock-server-1.26.62.1.zip` из [пользовательской папки Google Диска](https://drive.google.com/drive/folders/16lHnvV-44iRJ06aAIvrZ4uqe7FBx8Z3x), ID `1n9iM9QaUsKEvD5oNMupJBHgBTbUsLSAS`. Временная копия архива после проверки удалена; в Git она намеренно не добавлена из-за размера. Её можно повторно получить из пользовательского источника по указанному ID и сверить контрольные суммы.

- Размер архива: **98 089 493 байта**; MD5 `4a23794a882b008d3f0a5fde8b338f55`; SHA-256 `50cdb466cddef99066b888e2198479a9b352ea1535f00820b0204e92baa1ab0a`.
- ZIP содержит 3384 файла и 719 записей каталогов; суммарный заявленный распакованный размер 333 490 861 байт. `ZipFile.testzip()` проверил CRC всех записей и вернул `None`, то есть ошибок CRC не обнаружено. Абсолютных путей и компонентов `..` при проверке имён нет; это не полная проверка безопасности архива.
- Есть файл `bedrock_server` размером 265 500 488 байт, `bedrock_server_how_to.html`, `server.properties`, ванильные behavior/resource packs и `definitions/`. Многие игровые данные упакованы в `*.brarchive`. Заголовок ванильного behavior manifest сообщает `version:[0,0,1]`, а не версию исполняемого сервера. `release-notes.txt` не содержит номера сборки. Таким образом, номер 1.26.62.1 пока известен только по имени архива и не подтверждён запуском либо независимой проверкой бинарного файла.
- Повторная проверка: все **3384** файла повторно прочитаны с CRC и индивидуальным SHA-256; полный [индекс путей и проверок](../data/server-file-index.json). 942 JSON разобраны стандартным JSON, ещё 31 — JSON5; 15 `.mcstructure` разобраны как little-endian NBT, шесть PNG проверены и декодированы, текстовые файлы прочитаны как UTF-8. **1608 `.nbt` прошли только ограниченное gzip-декодирование**, их дерево NBT целиком не разбиралось. В 658 `.brarchive` далее выделены записи методом ниже. **Четыре других двоичных файла**, включая исполняемый сервер, только прочитаны и хэшированы; их содержимое и поведение не изучены семантически. Одна диагностическая попытка неверного порядка байтов для NBT была остановлена по превышению времени и памяти; исходники не изменялись.
- Экспериментальный разбор `.brarchive`: установлена согласованная для этого ZIP структура заголовка и записей фиксированного размера, проверены границы и непрерывность вложенных данных. Все **658** контейнеров содержат **9543** записи. Из них **7801** содержат байты внутри контейнера: 7236 JSON разобраны, 238 PNG декодированы, 15 JS только прочитаны как UTF-8; 312 файлов с расширением `.json` начинаются с сигнатуры `7f 4d 43 42` (`MCB`), их двоичный формат не декодирован, **нельзя называть их испорченным JSON**. Ещё 1742 записи в таблицах имеют нулевую длину; для каждой существует одноимённый кандидат вне brarchive в ZIP (1608 NBT, 116 lang, 15 mcstructure, 3 dat). Совпадение путей — наблюдение и гипотеза, не доказательство правил разрешения в движке. [Полный индекс](../data/server-brarchive-index.json), воспроизведение: `python tools/build_brarchive_index.py --server-zip /путь/bedrock-server-1.26.62.1.zip`. Формат выведен из одного архива, не из официальной спецификации; никакой код не исполнялся.
- Найдены 12 файлов `player.json` в разных внутренних vanilla-пакетах. [Сравнение с тремя аддонами](server-player-comparison.md) выявило, что base `vanilla` содержит exhaustion max 4 и saturation value 20, как аддон, а ряд других внутренних пакетов — max 20 и value 5, как два внешних образца. Нельзя автоматически приписать разницу версии ванили аддону или определить активный pack stack.
- Для повтора: `python tools/build_server_file_index.py --server-zip /путь/bedrock-server-1.26.62.1.zip`; проверяются хэши ZIP, чтение потоковое, файлы из него не извлекаются.
- Сервер **не распаковывался и не запускался**. ZIP CRC и хэши подтверждают целостность при чтении, но не подлинность или безопасность исполняемого файла и не подтверждают совместимость аддона. Игровые или серверные тесты не проведены; наличие выделенного сервера само по себе не даёт доступа к клиентским визуальным наблюдениям. Для полноценного сравнения нужна подходящая исходная версия Bedrock и согласованная изолированная среда; не делать вывод о 26.62 по одному наличию файла.
