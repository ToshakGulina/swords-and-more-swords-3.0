# Группы всех разбираемых behavior-сущностей — 2.8.8 и 2.8.14

Включены все файлы `entities/*.json` behavior pack, в том числе `minecraft:player`: разобранных файлов: **51**, локальных групп: **198**, объявлений событий: **303**; неразобранные файлы перечислены ниже. Для каждого файла извлечены объявления и буквальные операции `add.component_groups` / `remove.component_groups` внутри его `events`, включая вложенные sequence/randomize. Путь содержит индекс элемента массива и не доказывает, что событие вызвано или ветвь прошла фильтры.

Это не полный граф событий: команды `event entity`, внешние вызовы, vanilla/runtime, загрузка сохранённых состояний, отсутствующие файлы, наследование и другие способы включения групп не интерпретируются. Поэтому отсутствие локальных add/remove **не означает** неиспользуемость или постоянное действие; порядок выполнения и разрешение конфликтов компонентов не устанавливаются. Ссылки на необъявленные группы — диагностические наблюдения, а не доказанные ошибки Bedrock. Названия компонентов в таблице приведены только для ориентации; значения — в оригинале и реестре сущностей.

Объявленные локальные группы: только add — 106; только remove — 1; ни add ни remove — 7. Имена групп, упомянутые в событиях, но не объявленные в том же файле: 2. Это количество **имён на файл**, не отдельных вызовов; всего элементов ссылок add 302, remove 124.

- Неразобранные файлы: `Swords_B/entities/creeper.json` (<string>:430 Unexpected "}" at column 3).
- Повторяющиеся ключи в разобранных файлах: `Swords_B/entities/living_flame.json`: `minecraft:fire_immune`; `Swords_B/entities/mountable_slime.json`: `despawn`; `Swords_B/entities/slime_king.json`: `minecraft:movement.jump`. JSON5 в таких объектах оставляет последнее значение; оригинал необходимо читать отдельно.

Сравнение 2.8.8/2.8.14: локальные объявления групп (включая их разобранные значения), количество событий и пути add/remove совпадают для всех разобранных файлов. Это **не** сравнение полных событий или прочих полей сущностей; например, `player.json` различается.
