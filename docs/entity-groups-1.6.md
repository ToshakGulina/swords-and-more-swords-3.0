# Группы всех разбираемых behavior-сущностей — 1.6

Включены все файлы `entities/*.json` behavior pack, в том числе `minecraft:player`: разобранных файлов: **28**, локальных групп: **31**, объявлений событий: **32**; неразобранные файлы перечислены ниже. Для каждого файла извлечены объявления и буквальные операции `add.component_groups` / `remove.component_groups` внутри его `events`, включая вложенные sequence/randomize. Путь содержит индекс элемента массива и не доказывает, что событие вызвано или ветвь прошла фильтры.

Это не полный граф событий: команды `event entity`, внешние вызовы, vanilla/runtime, загрузка сохранённых состояний, отсутствующие файлы, наследование и другие способы включения групп не интерпретируются. Поэтому отсутствие локальных add/remove **не означает** неиспользуемость или постоянное действие; порядок выполнения и разрешение конфликтов компонентов не устанавливаются. Ссылки на необъявленные группы — диагностические наблюдения, а не доказанные ошибки Bedrock. Названия компонентов в таблице приведены только для ориентации; значения — в оригинале и реестре сущностей.

Объявленные локальные группы: только add — 3; только remove — 0; ни add ни remove — 0. Имена групп, упомянутые в событиях, но не объявленные в том же файле: 0. Это количество **имён на файл**, не отдельных вызовов; всего элементов ссылок add 31, remove 28.

- Неразобранные файлы: `Sword_B/entities/blaze2.json` (<string>:78 Unexpected "}" at column 1); `Sword_B/entities/bone2.json` (<string>:75 Unexpected "}" at column 1); `Sword_B/entities/shulker2.json` (<string>:75 Unexpected "}" at column 1).
- Повторяющиеся ключи в разобранных файлах: нет. JSON5 в таких объектах оставляет последнее значение; оригинал необходимо читать отдельно.
