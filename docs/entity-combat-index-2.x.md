# Компоненты боя и уязвимости сущностей — 2.8.8 и 2.8.14

Из **51** разобранных behavior entity файлов выбраны все значения 11 точных ключей только в базовом `components` и объявленных `component_groups`: **156 объектов/значений**, файлов с выбранным ключом — 36. Сохранены целые объекты, вложенные triggers и filters, списки и порядок. Близко называющиеся события `minecraft:explode` не принимаются за одноимённый компонент.

Это индекс **деклараций**, не итоговые характеристики: группа может быть неактивна, несколько групп могут задавать конфликтующие компоненты, события могут не вызываться, target и контекст определяются отдельно. `damage_sensor`, `hurt_on_condition` и `on_death` не дают полного графа последствий. Значения health относятся к сущностям, а не к прочности предмета. Отсутствующее поле не означает false, ноль, иммунитет либо непробиваемость. Источники ошибок/повторов ниже; поведение движка, vanilla/runtime и внешние пакеты не устанавливаются.

Число вхождений выбранных ключей: `minecraft:damage_sensor` — 40, `minecraft:health` — 29, `minecraft:attack` — 18, `minecraft:attack_damage` — 1, `minecraft:explode` — 12, `minecraft:fire_immune` — 8, `minecraft:breathable` — 17, `minecraft:knockback_resistance` — 6, `minecraft:hurt_on_condition` — 17, `minecraft:on_death` — 6, `minecraft:on_hurt` — 2.

- Исключены неразобранные файлы: `Swords_B/entities/creeper.json` (<string>:430 Unexpected "}" at column 3). Для Creeper 2.x есть отдельная [диагностика](manual-creeper-sword.md); безусловно считать его отсутствующим нельзя.
